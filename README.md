# Integrador-Dis.Web

Cuando descarguen el archivo, y abran el VSCode, abran un nuevo terminal y ejecuten el comando 'composer update' por otro lado, pueden volver a generar el autoload.php con el comando 'composer dump-autoload'. Todo esto por el terminal.

**IMPORTANTE: Deben tener instalado composer -> [Composer](https://getcomposer.org/download/)**
